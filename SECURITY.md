# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---               |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **Handbook**, please report it responsibly:

1. **Do not create a public issue**.
2. Report the vulnerability via GitHub's Private Vulnerability Reporting or email the maintainer directly.
3. Include detailed steps to reproduce the vulnerability.
4. You will receive an initial response within 48 hours acknowledging receipt of your report.

We appreciate your responsible disclosure and assistance in keeping Handbook safe.
